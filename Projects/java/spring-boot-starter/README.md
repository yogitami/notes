# Spring Boot Starter (Maven)

A minimal Spring Boot starter project in this notes workspace.

## Prerequisites

- Java 17+
- Maven 3.9+

## Run tests

```bash
mvn test
```

## Run app

```bash
mvn spring-boot:run
```

## Try endpoint

```bash
curl http://localhost:8080/api/hello
```

Expected response:

```text
Hello from Spring Boot starter!
```
